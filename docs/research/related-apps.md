# Related applications

The original survey compared open-source household managers, reward charts and commercial chore apps using repository documentation, store listings and published screenshots. A listing can establish that a feature is advertised. It cannot establish that a child understands it.

OpenChore was a close match for profile selection, guardian PINs, approvals, adjustments and rewards. DoneTick and Grocy were useful references for recurring household work. The project chose to build a narrower interface for Brazilian Portuguese households, picture-led task selection and guardian-confirmed reward spending. A self-hosted general household manager would have brought features outside the family trial.

Three prototype directions explored a list of cards, a compact alternative and a visual board. Today uses a grid of large pictures; opening a tile explains the task before the child confirms it. A meaningful pilot question is whether a child recognizes an action such as making the bed from a picture of its object.

Sources: [OpenChore](https://github.com/liftedkilt/openchore), [DoneTick](https://github.com/donetick/donetick), [Grocy](https://github.com/grocy/grocy), [original survey and source annotations](https://github.com/marceloavf/todo-kids/blob/f854579/docs/research/apps-similares.md).

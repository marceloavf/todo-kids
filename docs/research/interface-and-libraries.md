# Interface and libraries

The child screen has to explain an action before a child can reliably read its title. Use a recognizable picture, a short label and optional read-aloud steps. Pair status colors with a visible shape or icon. Keep targets large, allow the grid to scroll, and make the main action possible with a single tap on each screen.

The original study compared avatar generators, emoji sets, fonts, component kits and animation libraries. Todo Kids ships a curated set of local Noto Emoji SVGs and Nunito font files. A consistent picture matters more here than the platform's default emoji style. The guardian area uses Lucide icons for conventional editing actions. New asset choices need a usable redistribution license and a notice in the build.

A task takes two deliberate taps: open the card, then confirm. Test with a child who does not read the label, with sound disabled, and with reduced motion enabled. Watch whether the child can tell a pending task from an approved one. Library availability or download size alone says little about that interaction.

# Glossary

Use these terms in issues, designs and database discussions. The Portuguese column gives the corresponding term in the app or its design vocabulary.

| English | Portuguese | Meaning |
| --- | --- | --- |
| Family | Família | The household that shares routines, a reward catalog and guardian access. Points belong to individual children. |
| Guardian | Responsável | An adult profile that sets routines, reviews work and manages points. Guardians in a family have the same permissions. |
| Child | Filho | A family member who completes assigned tasks and earns their own points. |
| Profile | Perfil | A guardian's or child's identity inside the family. A family login can contain multiple profiles. |
| Child device | Aparelho do filho | A phone or tablet linked by a guardian to one child. It opens directly in that child's profile. |
| Link code | Código de vínculo | A short, single-use code that pairs a child device. The QR carries the same code. |
| Family day | Dia da família | A calendar date in the family's time zone. It determines which tasks apply and which day receives a child's completion. |
| Routine | Rotina | An ordered set of tasks assigned to one or more children on selected weekdays. |
| Task | Tarefa | An action with a name, picture, explanation, point value and approval setting. |
| Explanation | Explicação | The description and optional steps that tell the child how to do a task. |
| Step | Passo | One instruction, optionally illustrated. The child confirms the whole task. |
| Task card | Cartão da tarefa | The view that opens from a task tile and lets the child read, listen or confirm completion. |
| One-off task | Tarefa avulsa | A task assigned for a single date outside a routine. |
| Completion | Conclusão | A record that a particular child finished a particular task on a particular family day. |
| Proof | Comprovação | A proposed photo attached to a completion. Outside the first release. |
| Approval | Aprovação | A guardian accepts a completion that requires review and releases its points. |
| Rejection | Reprovação | A guardian asks for another attempt. The task can be retried that day. |
| Hint | Dica | An optional short instruction attached to a rejection. |
| Pending item | Pendência | A completion awaiting approval or a reward request awaiting a decision. |
| Points | Pontos | Whole units a child earns from tasks and can spend on family rewards. |
| Balance | Saldo | The points currently available to one child. |
| Statement | Extrato | The child's record of credits and debits. |
| Reversal | Estorno | The statement entry resulting from a guardian undoing a completion. |
| Adjustment | Ajuste | A manual bonus or deduction with a reason supplied by a guardian. |
| Reward | Recompensa | An experience or item a guardian offers for a stated point cost. |
| Redemption | Resgate | A child's request for a reward. The balance is debited when a guardian confirms it. |
